Calculator (Kotlin, no external libraries) - full-screen app + resizable home-screen widget

BUILD ONLINE (GitHub Actions, free):
1. Upload ALL the contents of this folder to your GitHub repository (Add file > Upload files).
2. Open the "Actions" tab; "Build APK" starts by itself (5-10 min). When it is green, open the run
   and download "calculator-apk" from Artifacts (zip containing app-debug.apk).
3. Uninstall the old app, install the new APK, then add the widget again
   (long-press the home screen > Widgets > Calculator).
